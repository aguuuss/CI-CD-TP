Esquema CI/CD del TP

Cambio en repo -> GitHub Actions -> typecheck/test/build -> deploy en Vercel -> feedback en Linear

Git + GitHub Control de versiones, ramas y merges
Codigo Vite + React + TypeScript
GitHub Actions Servidor de IC/CD
pnpm install typecheck Vitest Testing Library Vite build feedback
Vercel Entorno de entrega. Deploy solo desde main.
Resultado Entrega exitosa o pipeline bloqueado
Equipo + entorno local Node.js, pnpm, VS Code y comandos locales
pnpm dev pnpm test pnpm build
Linear Mecanismo de feedback: comentario automatico con exito o error
